# Agent-task eval summary, 2026-10-21

Model `sonnet` (Claude Code 2.1.306), 2 trials per task and configuration, the
same prompt, limits, and settings in every run. Baseline is the plugin at
`origin/main` (`6d2b5f8`); revised is this branch. Raw rows are in the JSON
files beside this one.

No run with a plugin loaded called a plugin skill, although all twelve were in

descriptions. A plain request does not reach the skills often enough for their
content to matter; this is recorded as an open risk in
`memory/bugs-and-risks.md`.

## Skill invoked: the prompt starts with the task's skill command

`2026-10-21-sonnet-invoked.md` (revised at `1ebfe2c`), with the `measure` rows
replaced by `2026-10-21-sonnet-invoked-measure-v2.md` (see below). 24 runs.

| Config | Correct | False success | Missed faults | Needless questions | Mean s | Mean $ | Mean input tokens | Small tasks correct |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| baseline | 7/12 | 5/12 | 4/8 | 0/12 | 12.5 | 0.059 | 78,901 | 2/6 |
| revised | 12/12 | 0/12 | 0/8 | 0/12 | 10.6 | 0.059 | 73,705 | 6/6 |

Where the two differed:

- `pr-ready` (small): baseline called a PR with an unpushed fix and an
  unresolved thread ready in both trials; revised said not ready in both.
- `measure` (small): baseline kept a change whose samples spread 180% because
  the user supplied zero noise; revised said measure again in both trials.
- `commit-staged`: baseline unstaged the user's note in one of two trials;
  revised left it staged and out of the commit in both.

The other three tasks were correct in every run on both. The trivial `typo`
task stayed small under the revised plugin: no extra files, 5 and 6 seconds,
$0.046 each run.

## A change made to the eval during the run

The first `measure` prompt listed "10, 100, 190" without saying they were
repeated runs, and every configuration read them as three input sizes, each
about 10% faster; under that reading KEEP is defensible. The prompt now says
they are three runs on the same input (`evals/tasks.mjs`), and only that task
was re-run, in both arms. With the plain prompt it scored none 1/2, baseline
0/2, revised 0/2, with no skill used; invoked, baseline 0/2 and revised 2/2.

## What this does not show

Two trials per cell, one model, six short single-language tasks. The invoked
arm shows what the skill content does once it is running; the plain arm shows
that, today, it rarely runs on its own. Codex was not run (no credentials).
